# Contributing to Digital Projections Watch

Keep changes focused and preserve upstream license notices. Add function-level tests for game rules and shared services, run `python scripts/test_watch.py`, and build the complete watch firmware. Include rendered UI evidence for layout changes and distinguish host checks from real-device tests.

Use the 2.06-inch board definition in `FirmWare/watch/components/dp_watch_board`. Bump VERSION and the firmware version for a release. Commit before flashing and keep private firmware backups, credentials, and generated build artifacts outside Git.

Open pull requests against this fork with the problem, resulting behavior, and validation performed.
